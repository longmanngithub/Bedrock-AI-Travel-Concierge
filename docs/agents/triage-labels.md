# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs a maintainer's evaluation |
| `needs-info` | `needs-info` | Waiting on information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Ready for human implementation |
| `wontfix` | `wontfix` | Work will not be taken up |

At setup, GitHub had `wontfix` and the other four names were pending. Check current labels before applying one. Until the corresponding label exists, report the proposed triage state in the review.
