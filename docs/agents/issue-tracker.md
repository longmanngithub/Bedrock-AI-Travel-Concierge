# Issue tracker

Project issues and specs live in GitHub Issues on `longmanngithub/Bedrock-AI-Travel-Concierge`. Use `gh repo view --json nameWithOwner` to verify the target, then use `gh issue view` or `gh issue list` to read it. Confirm authorization before publishing, labeling, assigning, commenting, or closing.

**PRs as a request surface: no.**

When publishing is authorized, create a GitHub issue for a spec. Link tickets to the parent spec and record blockers using native issue dependencies where available. If the tracker lacks that feature, write a `Blocked by: #<number>` line in the issue body. Use the open blockers to establish which ticket can start.
